# Jin Rong Cheng — Personal Website

Static multi-page personal website designed for GitHub Pages.

## Files
- `index.html`: homepage
- `about.html`: biography and interests
- `experience.html`: selected experience
- `projects.html`: initiatives and projects
- `writing.html`: research interests and writing archive
- `contact.html`: contact page
- `style.css`: responsive visual design
- `script.js`: mobile navigation and footer year
- `CNAME`: custom domain (`jrcheng.com`)

## Publish
In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
