# Jin Rong Cheng — Personal Website

A responsive multi-page personal portfolio for GitHub Pages.

## Files
- `index.html`: homepage
- `about.html`: biography and interests
- `experience.html`: selected experience
- `projects.html`: initiatives and projects
- `writing.html`: research interests
- `contact.html`: contact links
- `style.css`: responsive visual design and motion
- `script.js`: mobile navigation, reveal transitions, and footer year
- `assets/`: locally hosted photographs
- `CNAME`: primary custom domain (`jinrongcheng.ca`)

## Publish
Upload the contents of this folder to the root of `jinrongcheng.github.io`. In GitHub Settings → Pages, set the custom domain to `jinrongcheng.ca`.

Some supporting editorial photography on the homepage is loaded from Unsplash. The personal portrait is hosted locally in `assets/`.

## Campaign v2
Full-screen portrait hero, Anton campaign type, navy/red/gold scheme (AOC-style bold type and portrait-first hero; Bradford-style three clear pillars), scroll progress, parallax hero, directional reveals, and count-up stats. Contact and footer link to Jin's LinkedIn. This is a personal site in campaign style, not a candidacy page: no vote/donate language.

## V3 hero
Split hero: portrait panel on the left, readable text panel on the right, so text never sits over the photo. Copy rewritten in first person with specific Willowdale, YINC, Ward 19, and Model UN detail.

## V4
Hero split 75% photo / 25% text, smaller headline and plain body text so the hero text is not squished. Copy toned down to plain, factual role descriptions, no self-praise.
